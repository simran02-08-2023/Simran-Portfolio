Lost & Found Intelligent Matching System

A Java-based web application for reporting lost and found items, managing user submissions, and building an intelligent matching workflow. The project is currently under active development.

Project Overview

Backend Development

About

The system is being developed with a Java web architecture using Jakarta Servlets, JSP and JDBC. MySQL is used for persistence, with Apache Tomcat as the application server.

Current Focus

  • User authentication and session handling
  • Lost and found item reporting
  • Database-backed item management
  • Servlet, service and DAO layer separation
  • Matching workflow for related reports
